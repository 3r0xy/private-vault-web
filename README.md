# Private Vault v0.3 — GitHub + Obsidian Live Preview

Личный web-интерфейс к Obsidian-подобному vault, который хранится в **private GitHub repository**.

## Что умеет v0.3

- Открывает private GitHub repository через fine-grained token.
- Читает и сохраняет обычные `.md` файлы без конвертации в HTML или собственный формат.
- **Live Preview:** заголовки, жирный, курсив, зачёркивание, inline code и обычные Markdown-ссылки выглядят оформленными прямо во время редактирования.
- Отдельная кнопка **Markdown** показывает исходный Markdown один-в-один.
- Маленькая панель форматирования: H1/H2, bold, italic, `[[link]]`, обычная ссылка, списки, todo, quote, code и image syntax.
- Obsidian-style `[[wiki-links]]`.
- Автоподсказки заметок после ввода `[[`.
- Поддержка `[[Заметка]]`, `[[Папка/Заметка]]`, `[[Заметка|alias]]`, `[[Заметка#Раздел]]`.
- В Live Preview существующая wiki-ссылка превращается в визуальный chip; клик открывает заметку.
- Неразрешённая wiki-ссылка показывается иначе и по клику предлагает новую заметку.
- Backlinks и исходящие ссылки.
- **Graph View:** узлы = заметки, рёбра = wiki-ссылки; drag, zoom, поиск, открытие заметки кликом.
- Импорт целой папки существующего Obsidian vault вместе с вложениями.
- Адаптивный интерфейс для компьютера и планшета.

## Почему Live Preview всё равно хранит Markdown

Редактор визуально прячет часть Markdown-разметки, но файл остаётся обычным текстом:

```md
# Поездка

Нужно купить **билеты** и посмотреть [[Токио]].
```

Этот же файл можно открыть в обычном Obsidian без экспорта/конвертации.

Для точного редактирования исходного синтаксиса есть переключатель **Markdown**.

## Технически

Live Preview построен на CodeMirror 6 с собственными decorations для Obsidian wiki-links и Markdown-разметки. CodeMirror загружается как ES module с CDN. Graph View использует D3.

Это статическое приложение: сервер приложения не требуется.

## Модель приватности MVP

**Важно:** обычный GitHub Pages не является приватным сайтом только потому, что repository private.

Поэтому архитектура разделена:

1. Код web-интерфейса размещается отдельно.
2. Все личные заметки находятся в **PRIVATE repository**.
3. Интерфейс получает заметки через GitHub API только после авторизации token.
4. Token не прописан в исходном коде; он хранится в `sessionStorage` текущей браузерной сессии.

Для долгосрочной версии лучше заменить ручной token на GitHub App/OAuth с короткоживущей сессией.

## 1. Создай private repository для заметок

Например `my-private-vault` и поставь visibility **Private**.

Если repository полностью пустой, сначала добавь туда `README.md`.

## 2. Fine-grained GitHub token

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.

Рекомендуемые права:

- Repository access: **Only select repositories**
- выбрать только repository с vault
- Repository permissions → **Contents: Read and write**

Никогда не вставляй token в `app.js`, `index.html`, commit или screenshot.

## 3. Разверни интерфейс

Создай отдельный repository, например `private-vault-web`, и положи туда:

- `index.html`
- `app.js`
- `styles.css`

В Settings → Pages включи публикацию из ветки `main`, root `/`.

## 4. Подключение на разных устройствах

На компьютере и планшете открой один и тот же адрес GitHub Pages и введи:

- GitHub owner
- имя private repository с vault
- fine-grained token

Token хранится только на текущем устройстве/в текущей браузерной сессии, поэтому на другом устройстве его нужно ввести отдельно.

## 5. Импорт Obsidian

Нажми **Импорт Obsidian** и выбери папку vault.

Импортируются `.md`, изображения, PDF и другие вложения. Служебная папка `.obsidian` пропускается.

Перед первым импортом желательно сделать резервную копию vault и сначала проверить небольшой тестовый vault.

## Горячие клавиши

- `Ctrl/Cmd + S` — сохранить
- `Ctrl/Cmd + B` — bold
- `Ctrl/Cmd + I` — italic
- после `[[` — подсказки заметок
- стрелки ↑/↓ + Enter/Tab — выбрать wiki-ссылку

## Ограничения текущей версии

- `![[image.png]]` и другие Obsidian embeds пока не отрисовываются непосредственно внутри Live Preview.
- В Graph View индекс строится простым проходом по заметкам; на очень большом vault потребуется отдельный индекс.
- Импорт большого vault делает много GitHub API-запросов и может быть медленным.
- Переименование заметки пока не переписывает автоматически все `[[ссылки]]` на неё.
- Нет обработки конфликта, если одна заметка одновременно изменена на двух устройствах.
- Нет autosave/offline режима.
- Live Preview покрывает основные элементы Markdown, но ещё не воспроизводит все плагины/расширения Obsidian.

## Безопасность

- Vault repository должен оставаться **Private**.
- Fine-grained token выдавай только одному repository и только необходимые права.
- Если token случайно попал в commit, screenshot или публичный чат — сразу revoke и создай новый.

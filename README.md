# luna

Приватные заметки и планер с хранением в GitHub.

Рабочий адрес с OAuth: https://luna-private-vault.k-media-circle.workers.dev/
Подключён `3r0xy/my-private-vault`; редактирование включено по запросу владельца.

## Вход через GitHub OAuth

Добавлена серверная версия: кнопка «Войти через GitHub», защищённая cookie сессии,
зашифрованное хранение токенов на backend и proxy только к настроенному vault.
Поддерживаются Node.js 24 с постоянным диском и бесплатный Cloudflare Workers
с SQLite Durable Object. Приложение и API работают на одном HTTPS-адресе.
На GitHub Pages сохранён прежний резервный вход; OAuth на одном Pages не работает.

Пошаговая регистрация OAuth App, размещение backend, ограничения `repo`,
настройки сессий и проверка iPad/PWA: [docs/github-oauth.md](docs/github-oauth.md).
Секреты задаются только на backend по `.env.example`. Запись в vault по умолчанию
запрещена; включайте её отдельно после проверки чтения.

## Зависимости без CDN

CodeMirror и D3 загружаются из `vendor/` с того же сайта. Эти готовые файлы
закоммичены, поэтому GitHub Pages продолжает публиковать корень репозитория
без отдельного шага сборки. Браузеру не нужны esm.sh или jsdelivr.

Чтобы обновить библиотеки, измените закреплённые версии и lock-файл, затем:

```sh
npm ci
npm run build
```

Коммитьте `package.json`, `package-lock.json` и обновлённый `vendor/` вместе.
Сборка сохраняет лицензии зависимостей в `vendor/LICENSES.txt` и использует
один экземпляр CodeMirror state/view для всех расширений.

## Проверки

```sh
npm test
npm run test:login
npm run test:browser
```

Для браузерных проверок установите Chromium командой `npx playwright install chromium`
или укажите установленный Edge: `BROWSER_CHANNEL=msedge` (в PowerShell:
`$env:BROWSER_CHANNEL='msedge'`). Также поддерживается `BROWSER_EXECUTABLE`.

Все запросы GitHub в браузерных проверках перехватываются и получают тестовые
ответы. Реальный token и приватный vault не используются. Проверки входа
запрещают внешние CDN, проверяют редактор и граф, сообщения об ошибках,
повторный вход, таймауты и работу при запрете sessionStorage/localStorage.

При сбое загрузки самого приложения форма показывает ошибку и кнопку
обновления. При запросах GitHub отображается состояние подключения, а через
15 секунд без ответа — понятная ошибка с возможностью повторить вход.

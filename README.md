# luna

Личный ежедневник, заметки и долгосрочные проекты с кошечкой и розовой темой.

[Открыть luna](https://3r0xy.github.io/private-vault-web/)

## Файлы

- `index.html`, `styles.css` — интерфейс и оформление.
- `app.js` — редактор, проводник, граф и недельный планер.
- `domain.mjs`, `task-hub.mjs` — работа со ссылками, будущими делами и проектами.
- `icons/`, `favicon.ico`, `manifest.webmanifest` — иконки и установка приложения.
- `docs/planning.md` — формат планов и задач.
- `tests/` — проверки на вымышленных данных.

## Разработка

Статический сайт без сборки. CodeMirror и D3 загружаются с CDN. Для локального просмотра запустите HTTP-сервер в корне проекта.

Проверки логики: `node --test tests/domain.test.mjs`.
Браузерные проверки: `node tests/browser.test.cjs` (нужны Playwright и Chromium).

Личные данные хранятся отдельно от кода сайта. Токен доступа вводится в приложении и хранится только в текущей браузерной сессии.
